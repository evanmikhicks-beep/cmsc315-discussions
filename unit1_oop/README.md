# Unit 1 Discussion: Python OOP, Namespaces, and Copying

## Overview

This assignment explores object-oriented programming (OOP) concepts in Python, including inheritance, namespaces, and object copying.

## Class Details

- The parent class Electronic represents an electronics store inventory, and the child class Drone represents one category of products.
- The Electronic class contains the name and price of an item.
- The Drone class adds weight, propulsion type, and battery watt-hours. An added method estimates flight hours.
- The Drone class overrides the getDetails method with the additional details.

## Implementation

- A demonstrate_namespaces method uses print statements to demonstrate use of namespaces.
- A demonstrate_copying method conducts both deep and shallow copies of instances.
- The main method creates instances of both the parent and child classes, uses method calls to demonstrate inheritance, and calls the methods for namespace and copying demonstration.
